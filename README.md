# 反差动物人格：纯静态版

答题、计分、报告分析和 PNG 长图导出均在用户浏览器中完成。网页不使用 Supabase、数据库、云函数、Google 登录或大模型 API。唯一额外读取的是同一网站上的公开静态密码哈希文件 access-codes.json；全部插画、样式和脚本随站点交付。

## 商业使用边界

密码入口和3次记录仅是当前浏览器的使用提示，不是安全付费墙。清除存储、换浏览器、换设备或修改前端代码可重置/绕过。不能统计全店消耗、全设备限制、追踪订单或实现服务端退款作废。网站源码及算法对用户可见。旧 Supabase/D1 密码不自动继承，旧服务的报告链接仍依赖旧网站。

## 交付文件

- `outputs/纯静态网站交付包.zip`：解压后，只把 `website/` 内的文件上传到网站。其他内容是店主说明和工具。
- `private/`：本批密码 CSV，仅给店主保管，不能放入公开网站。
- `merchant/店主离线密码工具.html`：可在电脑双击打开，批量生成密码及自动填码链接，不需在线后台。
- `nginx.conf`：Linux Nginx 的静态配置示例。局域网用 HTTP 时复制链接可通过手动复制完成；公开站点建议 HTTPS。

## 使用步骤

1. 上传 website 文件夹的内容，使 index.html 位于网站根目录。OSS/COS 设置 index.html 为首页，使用自定义域名与 HTTPS。不要上传源码、private 或店主 CSV。
2. 向自动发货工具导入店主 CSV 中的“测试密码”列，每单发一个密码，配合固定测评网址。不要发送管理工具地址。
3. 需要新密码时，打开离线工具，先导入当前网站的 access-codes.json，生成新一批，再将更新后的 JSON 覆盖上传到网站。旧密码需要保留时不能跳过导入步骤。批量删除 JSON 中对应哈希可以使密码在刷新后的新登录中失效，但不能撤销别人已经复制的静态程序。
4. 如果填写测评网址，工具同时导出 `#/start/密码` 链接。顾客打开后自动填码，点击开始后在本地验证。专属链接等同密码；分享报告使用结果页的复制按钮。
5. 原浏览器通过 `#/result/本地ID` 读取本地报告；跨浏览器分享使用 `#/share/结果数据`。分享链接仅包含组合、日期和通用分析线索，不包含原始答案、密码、答题场景或本地次数。分享内容没有服务器签名，不能作为真实性证明。
6. 报告保存为 PNG。手机可长按预览图，或使用系统分享；是否直接保存到相册取决于浏览器和系统。电脑可以下载。

## 内网与国内公网

把 website 放到局域网 Nginx 下，只能供能连接这张局域网的设备使用。小红书各地顾客需要公网入口。中国大陆地域的对象存储静态网站需按服务商要求使用域名和备案，不因“无后端”而免除。GitHub Pages 不能保证国内网络可达，也有商业托管使用限制。

HTTPS 网站中的理论参考链接只在用户主动点击时访问外部论文/理论网站，不影响测评。不要用“完全禁止外网所有请求”的企业内网环境来推断全国顾客的可达性；上线前分别验收手机流量和家庭宽带。

## 本地开发与打包

Node 22.13+。`npm ci`、`npm test`、`npm run codes -- 100`、`node scripts/build-merchant.mjs`、`npm run build`、`npm run pack`。开发预览 `npm run dev`；构建预览 `npm run preview`。不能通过双击 website/index.html 代替 HTTP 静态托管，因为模块脚本受浏览器本地文件限制。密码工具是独立单文件，可双击运行。

站点支持根目录和子目录部署，使用哈希路由，不要求后端重写。保持部署域名和路径稳定，否则浏览器存储的来源发生变化，本地次数和报告记录无法自动继承。
